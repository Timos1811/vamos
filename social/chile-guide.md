## קרוסלה 1 — "תפוח אחד בתיק יכול לעלות לכם מאות דולרים בגבול צ׳ילה"

זווית: הפיקוח החקלאי הנוקשה של צ׳ילה — עובדה מפתיעה וקונקרטית שכל מטייל צריך לדעת.

| סלייד | טקסט | כיוון ויזואלי |
|---|---|---|
| 1 (הוק) | תפוח אחד שנשכח בתיק יכול לעלות לכם מאות דולרים בגבול צ׳ילה 🍎🚫 | תמונת גבול/מכס |
| 2 | לצ׳ילה יש פיקוח חקלאי מהנוקשים בעולם — היא נקייה ממחלות ומזיקים חקלאיים רבים | |
| 3 | אסור להכניס: פירות, ירקות, זרעים, אגוזים, דבש, מוצרי בשר וחלב | |
| 4 | בכל כניסה (גם יבשתית!) ממלאים טופס הצהרה, והתיקים עוברים סריקה וכלבים | |
| 5 | פריט לא מוצהר = קנס של מאות דולרים. הצהרה על אותו פריט = פשוט זריקה לפח | |
| 6 | הכלל: לפני הגבול מסיימים את הפירות. יש ספק? מצהירים | |
| 7 (CTA) | כל כללי הכניסה לצ׳ילה — בלינק בביו | לוגו VAMOS |

**כיתוב לפוסט:**
> העובדה שתופסת הכי הרבה מטיילים בגבול צ׳ילה: התפוח שנשאר בתיק מהאוטובוס 🍎🚫
> המדינה שומרת בקנאות על החקלאות שלה, וזה אומר בדיקה רצינית בכל כניסה — גם מבוליביה או ארגנטינה.

## קרוסלה 2 — "כמה עולה טיול בצ׳ילה? (המדינה היקרה ביבשת)"

זווית: טבלת המחירים + הכנה למכה של פטגוניה. פורמט "שמרו את זה".

| סלייד | טקסט | כיוון ויזואלי |
|---|---|---|
| 1 (הוק) | צ׳ילה יקרה פי 2 מבוליביה ופרו. הנה בדיוק כמה 💸 | תמונת סנטיאגו/אנדים |
| 2 | מיטה בהוסטל: 18–30$. ארוחת צהריים עסקית (menú del día): 6–10$ | |
| 3 | אוטובוס לילה סנטיאגו–פוארטו מונט: 30–55$. טיסת פנים: 50–130$ בהזמנה מראש | |
| 4 | כניסה לטורס דל פאינה: כ-35$. לילה ברפוחיו כולל ארוחות: 90–160$ | |
| 5 | שורה תחתונה: 45–65$ ליום. פטגוניה מקפיצה שבוע ל-600–900$ | |
| 6 | 3 שבועות עם טרק ה-W וטיסת פנים: כ-1,600–2,200$ לאדם | |
| 7 (CTA) | הטבלה המלאה + טיפים לחיסכון — בלינק בביו | לוגו VAMOS |

**כיתוב לפוסט:**
> צ׳ילה היא המדינה היקרה ביבשת — אבל יש דרך חכמה לעשות אותה 💸
> קונים אוכל בסופר הגדול, אוכלים בצהריים כשיש מנו דל דיה, ושוכרים ציוד טרק במקום לגרור מהארץ.
>
> מתכננים תקציב לצ׳ילה? 👇
>
> הטבלה המלאה בלינק בביו.

## קרוסלה 3 — "18 יום בצ׳ילה: מהמדבר היבש בעולם ועד קרחונים בפטגוניה"

זווית: המסלול המומלץ, listicle תחנה־תחנה. 4,300 ק"מ אורך = הכי דרמטי מכל המדריכים.

| סלייד | טקסט | כיוון ויזואלי |
|---|---|---|
| 1 (הוק) | 18 יום בצ׳ילה — 4,300 ק"מ ממדבר צחיח ועד קרחונים 🏔️ | מפת צ׳ילה המוארכת |
| 2 | 1️⃣ **סן פדרו דה אטקמה** (3 ימים) — המדבר היבש בעולם, גייזרים לפני הזריחה, שמיים מהצלולים בעולם | תמונת מדבר/כוכבים |
| 3 | 2️⃣ **סנטיאגו** (יומיים) — אנדים מושלגים ברקע, מוזיאון הזיכרון לתקופת הדיקטטורה | תמונת עיר/הרים |
| 4 | 3️⃣ **ולפראיסו** (יומיים) — עיר נמל שנשפכת במורד גבעות, כולה גרפיטי ומעליות עתיקות | תמונת גרפיטי/מעלית |
| 5 | 4️⃣ **פוקון** (3 ימים) — טיפוס על הר געש פעיל, לוע מעשן, מעיינות חמים | תמונת הר געש |
| 6 | 5️⃣ **פוארטו ואראס וצ׳ילואה** (יומיים) — אגם ענק מול 2 הרי געש, כנסיות עץ, בתי כלונסאות | תמונת אגם/כנסיית עץ |
| 7 | 6️⃣ **טורס דל פאינה** (5 ימים) — טרק ה-W: מגדלי גרניט, קרחון גריי, זריחה מהאגדיות ביבשת | תמונת מגדלי פאינה |
| 8 (CTA) | המסלול המלא + תוספת איי הפסחא — בלינק בביו | לוגו VAMOS |

**כיתוב לפוסט:**
> מדינה בקושי 180 ק"מ רוחב — אבל 4,300 ק"מ אורך, מסהרה ועד אנטארקטיקה 🏔️
> 18 יום בצ׳ילה נותנים לכם מדבר, עיר גרפיטי, הר געש פעיל ואת אחד הטרקים היפים בעולם.
>
> איזו תחנה הכי קוראת לכם? 👇

## קרוסלה 5 — "רעידת אדמה בצ׳ילה? הנה בדיוק מה עושים"

זווית: פרוטוקול רעידות האדמה + כללי בטיחות נוספים — ייחודי, מעניין, "מידע שמצילים ממנו".

| סלייד | טקסט | כיוון ויזואלי |
|---|---|---|
| 1 (הוק) | צ׳ילה על אחד האזורים הרעידתיים הכי פעילים בעולם. מה עושים אם קורה? 🌍 | תמונת נוף עירוני |
| 2 | רעידות קלות מורגשות כמה פעמים בשנה. הבניינים בנויים לזה — הבהלה מיותרת | |
| 3 | בזמן רעידה: נשארים בפנים, מתרחקים מחלונות, ליד קיר נושא או מתחת לשולחן יציב | |
| 4 | לא רצים למדרגות, ובוודאי לא למעלית | |
| 5 | אחרי רעידה חזקה ליד חוף: עולים לגובה **מיד**, לא ממתינים להנחיה — סיכון צונאמי | |
| 6 | בונוס: הגניבה הכי נפוצה היא לא ברחוב אלא מרכב חונה. לא משאירים כלום, תמיד | |
| 7 (CTA) | כל כללי הבטיחות המלאים — בלינק בביו | לוגו VAMOS |

**כיתוב לפוסט:**
> מידע שכל מטייל בצ׳ילה צריך — ורוב המדריכים לא מזכירים 🌍
> רעידות אדמה הן חלק מהחיים שם. הפרוטוקול פשוט, אבל כדאי לדעת אותו לפני שקורה, לא תוך כדי.
>
> ידעתם את הכללים? 👇
>
> כל כללי הבטיחות המלאים בלינק בביו.
