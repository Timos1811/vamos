## קרוסלה 1 — "מאצ׳ו פיצ׳ו לא עולה 50 דולר. היא עולה עד 400"

זווית: מיתוס-הניפוץ הכי חזק בכתבה — ההבדל בין מחיר הכניסה למחיר האמיתי. הכי save-worthy.

|---|---|---|
| 1 (הוק) | חושבים שמאצ׳ו פיצ׳ו עולה 50 דולר? זה רק חלק קטן מהסיפור 💸 | תמונת מאצ׳ו פיצ׳ו |
| 2 | הכניסה עצמה: 45–60$ בלבד — זה באמת לא נורא | |
| 3 | הבעיה: אין כביש לאגואס קליינטס, העיירה שלמרגלות האתר. חייבים רכבת | |
| 4 | הרכבת מאולנטייטמבו: 60–140$ **הלוך-חזור** — אחת היקרות בעולם ליחידת מרחק | |
| 5 | + אוטובוס לשער (24$), + לילה באגואס קליינטס, + לרוב מדריך | |
| 6 | שורה תחתונה: 200–400$ לאדם. לא סיבה לוותר — סיבה לתכנן נכון | |
| 7 | טיפ לחוסכים: יש מסלול יבשתי חלופי דרך הידרואלקטריקה — חוסך כ-100$ (מתיש, יום שלם הליכה) | |
| 8 (CTA) | כל הפירוט + הטריק לחיסכון — בלינק בביו | לוגו VAMOS |

**כיתוב לפוסט:**

> אין כביש לאתר, אז הרכבת היחידה שמגיעה לשם היא מהיקרות בעולם. התקציב האמיתי: 200-400$ לאדם.

## קרוסלה 3 — "3 שבועות בפרו: מהמדבר ועד מאצ׳ו פיצ׳ו"

| 4 | 3️⃣ **נאסקה** — טיסה קטנה מעל דמויות ענק שנחרטו במדבר לפני 2,000 שנה | תמונת קווי נאסקה |
| 5 | 4️⃣ **ארקיפה וקניון קולקה** — העיר הלבנה, ואז קונדורים גולשים מעל אחד הקניונים העמוקים בעולם | תמונת קונדור |
| 6 | 5️⃣ **פונו וטיטיקקה** — האגם השיט הגבוה בעולם, 3,800 מטר, לינה עם משפחה על אי צף | תמונת אגם טיטיקקה |
| 7 | 6️⃣ **קוסקו והעמק הקדוש** — בירת האינקה לשעבר, אדריכלות שרדה רעידות אדמה | תמונת קוסקו |
| 8 | 7️⃣ **טרק + מאצ׳ו פיצ׳ו** — סלקנטאי (5 ימים) או האינקה (4 ימים), שניהם מסתיימים באתר | תמונת מאצ׳ו פיצ׳ו |
