## קרוסלה 1 — "אי אפשר לנסוע מפנמה לקולומביה ביבשה. בכלל."

זווית: עובדת הדארין גאפ מהכתבה — הכי מפתיע וסוחף בכל הכתבה, מיתוס-ניפוץ אמיתי.

| סלייד | טקסט | כיוון ויזואלי |
|---|---|---|
| 1 (הוק) | חשבתם שאפשר לנסוע מפנמה לקולומביה באוטובוס? אי אפשר. בכלל 🚫 | תמונת ג׳ונגל/מפה |
| 2 | הכביש הבין-אמריקאי חוצה את כל היבשת — חוץ ממקום אחד | |
| 3 | בין פנמה לקולומביה משתרע מצוק הדרין (Darién Gap): כ-100 ק"מ של ג׳ונגל וביצות | |
| 4 | אין כביש, אין תחבורה, ואין "מסלול קשה למי שרוצה אתגר" | |
| 5 | האזור בשליטת ארגוני פשע וכנופיות הברחה, ומדי שנה נעלמים בו אנשים | |
| 6 | הדרכים האמיתיות: טיסה קצרה (פחות משעה וחצי) לקרטחנה, או הפלגת מפרש של 4-5 ימים דרך סן בלאס | |
| 7 (CTA) | כל הפרטים על שתי האופציות — בלינק בביו | לוגו VAMOS |

**כיתוב לפוסט:**
> העובדה שהכי מפתיעה את כולם לפני פנמה: אי אפשר להגיע ביבשה לקולומביה 🚫
> היבשת פשוט "נגמרת" בג׳ונגל שאין בו כביש. יש רק שתי דרכים אמיתיות להמשיך — וכדאי לתכנן אותן מראש.
>
> ידעתם על זה? 👇
>
> כל הפרטים על טיסה מול הפלגת סן בלאס בלינק בביו.

## קרוסלה 2 — "כמה עולה טיול בפנמה? (במטבע שכבר מכירים)"

זווית: טבלת המחירים + הזווית הייחודית שהמטבע הוא דולר אמריקאי ישירות.

| סלייד | טקסט | כיוון ויזואלי |
|---|---|---|
| 1 (הוק) | פנמה היא המדינה היחידה במרכז אמריקה שמשלמים בה... דולר. ישירות 💵 | תמונת שטרות דולר/מפרץ פנמה |
| 2 | הבלבואה צמוד לדולר 1:1, והשטרות בפועל הם פשוט שטרות דולר. אין המרה, אין חישובים | |
| 3 | מיטה בהוסטל: 15–25$. ארוחה מקומית (קסאדו/פונדה): 5–8$ | |
| 4 | טיסת פנים לבוקאס דל טורו: 100–180$ לכיוון. חוסכת יום שלם של אוטובוס+סירה | |
| 5 | סיור יום לסן בלאס: 130–180$. הפלגה של 5 ימים לקרטחנה: 550–750$ | |
| 6 | שורה תחתונה: 40–50$ ליום. שבועיים עם סן בלאס וצלילה = 900–1,300$ | |
| 7 (CTA) | הטבלה המלאה — בלינק בביו | לוגו VAMOS |

**כיתוב לפוסט:**
> פנמה היא המדינה היחידה במרכז אמריקה שבה פשוט משלמים בדולר — בלי חישובי המרה 💵
> וזה עושה תכנון תקציב הרבה יותר קל. הנה כל המחירים שצריך לדעת.
>
> מתכננים תקציב לפנמה? 👇
>
> הטבלה המלאה בלינק בביו.

## קרוסלה 3 — "שבועיים בפנמה: המסלול מבירה קולוניאלית ועד איים קריביים"

זווית: המסלול המומלץ מהכתבה, listicle תחנה־תחנה.

| סלייד | טקסט | כיוון ויזואלי |
|---|---|---|
| 1 (הוק) | שבועיים בפנמה — מקו רקיע מודרני ועד אי עם 3 דקלים בלבד 🇵🇦 | מפת פנמה |
| 2 | 1️⃣ **פנמה סיטי** (יומיים) — קסקו ויחו הקולוניאלי, מנעולי תעלת פנמה במירפלורס | תמונת קסקו ויחו |
| 3 | 2️⃣ **איי סן בלאס** (יומיים) — בקתה על אי בגודל מגרש כדורגל, בלי חשמל ובלי קליטה | תמונת איים טורקיז |
| 4 | 3️⃣ **אל ואייה דה אנטון** (יום) — עיירה בתוך לוע הר געש כבוי, אוויר קריר ומפלים | תמונת הר געש |
| 5 | 4️⃣ **פלאיה ונאו** (יומיים) — חוף גלישה נוח ללומדים, אווירת כפר קטן | תמונת גולשים |
| 6 | 5️⃣ **סנטה קטלינה** (יומיים) — בסיס לצלילה בפארק קויבה: כרישי ריף, צבים, להקות ענק | תמונת צלילה |
| 7 | 6️⃣ **בוקטה** (יומיים) — עיירת הרים ב-1,200 מטר, קפה גישה — מהיקרים בעולם | תמונת מטעי קפה |
| 8 | 7️⃣ **בוקאס דל טורו** (3 ימים) — ארכיפלג קריבי, הוסטלים על כלונסאות, שנרקול | תמונת בקתות מים |
| 9 (CTA) | המסלול המלא + טיפים לכל תחנה — בלינק בביו | לוגו VAMOS |

**כיתוב לפוסט:**
> משפה קולוניאלית ומגדלי זכוכית ועד אי קריבי עם בקתה אחת — כל זה בפנמה אחת 🇵🇦
> שבועיים מספיקים כדי לראות את שני האוקיינוסים, את התעלה ואת הג׳ונגל, בלי לרוץ.
>
> איזו תחנה הכי קוראת לכם? 👇

## קרוסלה 4 — "פנמה בטוחה — אבל 3 נקודות שכן צריך להכיר"

זווית: פרק הבטיחות — ספציפי (קולון, בוקאס דל טורו, קסקו ויחו בלילה), לא גנרי.

| סלייד | טקסט | כיוון ויזואלי |
|---|---|---|
| 1 (הוק) | פנמה מהמדינות הבטוחות במרכז אמריקה. 3 נקודות שכן חייבים להכיר 📍 | טקסט על רקע מפה |
| 2 | **קולון** — עיר הנמל בקצה התעלה. פשיעה גבוהה משמעותית, גם באור יום. אין סיבה תיירותית לעצור בה | |
| 3 | **בוקאס דל טורו** — חופי הצד הפתוח (בלאף, וויזארד ביץ׳) יפים אבל עם זרמי קרע חזקים ובלי מצילים | |
| 4 | סיבת המוות מספר 1 של מטיילים באזור — לרוב אחרי אלכוהול. לא נכנסים לבד, לא שיכורים | |
| 5 | **קסקו ויחו** (הבירה) — מפוקח בלב, אבל השוליים פחות. לא יוצאים רגלית בלילה, לוקחים אובר | |
| 6 | ולבסוף: מצוק הדרין הוא לא "מסוכן" — הוא **אסור**. אין שם ביטוח שיכסה אתכם | |
| 7 (CTA) | המדריך המלא לבטיחות באזור — בלינק בביו | לוגו VAMOS |

**כיתוב לפוסט:**
> פנמה נחשבת בטוחה — אבל יש 3 נקודות ספציפיות שכדאי לדעת מראש 📍
> לא פחד גורף, רק כללים ברורים: איפה לא לעצור, איפה לא לשחות לבד, ואיפה לא ללכת רגלית בלילה.
>
> שומרים את הפוסט למי שטס לפנמה? 👇

## קרוסלה 5 — "איי סן בלאס: מה שצריך לדעת לפני שטסים לשם"

זווית: המידע הפרקטי הייחודי על סן בלאס — טריטוריה אוטונומית, מזומן בלבד, בלי כספומט.

| סלייד | טקסט | כיוון ויזואלי |
|---|---|---|
| 1 (הוק) | איי סן בלאס: הים הכי טורקיזי בפנמה. אבל יש כללים שחייבים להכיר 🏝️ | תמונת איים טורקיז |
| 2 | סן בלאס היא לא "אתר תיירות" — היא טריטוריה אוטונומית של עם הגונה (Guna Yala) | |
| 3 | יש להם חוקים משלהם, כולל איסור לצלם אנשים בלי רשות | |
| 4 | ההגעה: 4x4 מפנמה סיטי בחמש בבוקר, שעתיים וחצי כביש הררי, ואז סירה | |
| 5 | **קריטי לדעת:** אין כספומט באיים. אין אשראי. הכול מזומן — פרטו לפני שאתם יוצאים | |
| 6 | עלות: סיור יום 130–180$, לינה עם ארוחות 100–150$ ללילה, + אגרת קהילתית 20–25$ | |
| 7 (CTA) | כל מה שצריך לדעת לפני סן בלאס — בלינק בביו | לוגו VAMOS |

**כיתוב לפוסט:**
> לפני שטסים לאיי סן בלאס — יש דבר אחד שממש לא כדאי לשכוח 🏝️
> אין שם כספומט. אין אשראי. אם נגמר לכם המזומן, אתם פשוט לא אוכלים. פרטו לפני שאתם יוצאים לאיים.
>
> תכננתם כבר את סן בלאס? 👇
>
> כל הפרטים המלאים בלינק בביו.
