## קרוסלה 1 — "למה קוסטה ריקה עולה כפול מהשכנות שלה?"

זווית: ההסבר בכתבה למה המדינה יקרה — מיתוס-ניפוץ עם תשובה אמיתית וייחודית (אין צבא, אקו־תיירות).

| סלייד | טקסט | כיוון ויזואלי |
|---|---|---|
| 1 (הוק) | קוסטה ריקה יקרה פי 2 מגואטמלה וניקרגואה. יש לזה סיבה אחת מפתיעה 🇨🇷 | תמונת ג׳ונגל/עצלן |
| 2 | ב-1948 קוסטה ריקה ביטלה את הצבא שלה — לגמרי | |
| 3 | את התקציב שהתפנה היא הפנתה לחינוך, בריאות ולשמורות טבע | |
| 4 | כרבע משטח המדינה היום הוא פארקים לאומיים ושמורות מוגנות | |
| 5 | זה אומר: דמי כניסה לכל פארק, מדריכים מוסמכים בשכר הוגן, מכסות מבקרים יומיות | |
| 6 | התוצאה: ג׳ונגל שבאמת נשמר — ומחיר שאתם משלמים עליו | |
| 7 (CTA) | כל הפירוט על מה משלמים וכמה — בלינק בביו | לוגו VAMOS |

**כיתוב לפוסט:**
> "למה קוסטה ריקה כל כך יקרה?" — יש לזה תשובה אחת שרוב האנשים לא מכירים 🇨🇷
> ב-1948 המדינה ביטלה את הצבא שלה, והפנתה הכול לשימור טבע. אתם לא משלמים על יוקר — אתם משלמים על הג׳ונגל שבאמת נשאר.
>
> שווה את זה בעיניכם? 👇
>
> המדריך המלא + כמה זה עולה בפועל — בלינק בביו.

## קרוסלה 2 — "כמה עולה טיול בקוסטה ריקה? התקציב המלא"

זווית: טבלת המחירים. פורמט "שמרו את זה" — המדינה היקרה ביותר במרכז אמריקה, אנשים צריכים לתכנן.

| סלייד | טקסט | כיוון ויזואלי |
|---|---|---|
| 1 (הוק) | קוסטה ריקה = המדינה היקרה ביותר במרכז אמריקה. הנה בדיוק כמה 💸 | טקסט על רקע חוף |
| 2 | מיטה בהוסטל: 15–25$. ארוחת קסאדו ב"סודה" מקומית: 4–7$ בלבד | |
| 3 | כניסה לפארק לאומי: 15–20$ **לכל פארק**. זה מצטבר מהר | |
| 4 | קנופי/זיפליין במונטוורדה: 50–75$. סיור בקורקובאדו עם מדריך: 90–150$ | |
| 5 | שורה תחתונה: תרמילאי חסכן — 50–70$ ליום. שבועיים = 900–1,300$ לאדם | |
| 6 | 3 דרכים לחתוך: לבשל בהוסטל, לוותר על מדריך בפארקים פתוחים, ולזכור שהחופים חינם בחוק | |
| 7 (CTA) | הטבלה המלאה + כל טיפי החיסכון — בלינק בביו | לוגו VAMOS |

**כיתוב לפוסט:**
> קוסטה ריקה יקרה — אבל יש דרך נכונה לעשות אותה 💸
> חוף חינמי, בישול בהוסטל, ובחירה של 2-3 פארקים במקום 7 — וזה כבר חוסך מאות דולרים.
>
> מתכננים תקציב לקוסטה ריקה? 👇
>
> הטבלה המלאה בלינק בביו.

## קרוסלה 3 — "מה באמת מסוכן בקוסטה ריקה? (רמז: זה לא מה שחשבתם)"

זווית: פרק הבטיחות — ניגוד חד בין הציפייה (פשע/חיות) למציאות (זרמי מים, פריצות לרכב).

| סלייד | טקסט | כיוון ויזואלי |
|---|---|---|
| 1 (הוק) | קוסטה ריקה נחשבת הכי בטוחה במרכז אמריקה. אז ממה באמת צריך להיזהר? 🌊 | תמונת חוף פסיפי |
| 2 | הגורם מספר 1 למקרי מוות של תיירים: זרמי מלכודת (rip currents) בחוף הפסיפי, לא פשע | |
| 3 | נסחפתם? אל תשחו נגד הזרם — שחו במקביל לחוף עד שיוצאים מהרצועה, ורק אז חזרו | |
| 4 | הפשע הכי נפוץ נגד תיירים: פריצה לרכב שכור בחניוני שבילים ומפלים. לא משאירים כלום, גם לא בתא מטען | |
| 5 | חיות: לא מאכילים קופים, נועלים נעליים סגורות בג׳ונגל (נחש הטרסיופלו), לא נכנסים למים עכורים (תנינים) | |
| 6 | בסן חוסה: לא הולכים ברגל בלילה, רק אובר או מונית אדומה עם מונה | |
| 7 (CTA) | כל כללי הבטיחות המלאים — בלינק בביו | לוגו VAMOS |

**כיתוב לפוסט:**
> קוסטה ריקה בטוחה — אבל לא מהדברים שאתם חושבים 🌊
> הסכנה האמיתית היא לא פשע, היא זרמי הים. וזה בדיוק למה כדאי לדעת את הכללים לפני שנכנסים למים.
>
> ידעתם על זה? 👇
>
> כל הטיפים המלאים בלינק בביו.

|---|---|---|

| 2 | גואטמלה, הונדורס, אל סלבדור וניקרגואה חולקות מכסה משותפת: 90 יום, ותו לא | |

| 5 | יציאה מניקרגואה לקוסטה ריקה מאפסת את המכסה המשותפת של ארבע המדינות מ-0 | |

## קרוסלה 5 — "בספטמבר כל המדינה גשומה — חוץ מהחוף הזה"

זווית: הטיפ על הפוך-לוח-שנה בחוף הקריבי + הפיכת מסלול. "מה שלא מספרים לכם".

| סלייד | טקסט | כיוון ויזואלי |
|---|---|---|
| 1 (הוק) | ספטמבר-אוקטובר: כל קוסטה ריקה גשומה. חוץ מחוף אחד ⛅ | תמונת חוף קריבי |
| 2 | החוף הקריבי (פוארטו וייחו, קהואיטה) עובד בלוח שנה הפוך משאר המדינה | |
| 3 | פברואר-מרץ, ובעיקר ספטמבר-אוקטובר — בדיוק כשכל שאר המדינה שוקעת במים | |
| 4 | הטיפ: מגיעים בסתיו? אל תילחמו בעונה — הפכו את המסלול | |
| 5 | רדו מניקרגואה ישר ללה פורטונה, ומשם חצו מדינה לצד הקריבי | |
| 6 | בונוס: זו גם עונת הקינון של צבי הים בטורטוגרו — הכול באותו חלון | |
| 7 (CTA) | לוח העונות המלא לפי אזור — בלינק בביו | לוגו VAMOS |

**כיתוב לפוסט:**
> טסים לקוסטה ריקה בספטמבר-אוקטובר? אל תבטלו — רק תהפכו את המסלול ⛅
> החוף הקריבי דווקא מתייבש בדיוק כשכל שאר המדינה נשטפת. תזמון נכון = מזג אוויר מושלם + צבי ים בטורטוגרו.
>
> מתי אתם מתכננים לטוס? 👇
